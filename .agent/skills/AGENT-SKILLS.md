# 🛠️ Agent Skills

> **Skills** extend agent capabilities for specialized tasks. 

## Available Skills

| Skill | Description | Location |
|-------|-------------|----------|
| **Example Skill** | An example skill structure | `./example-skill/SKILL.md` |

## Adding New Skills

1. Create a folder in `.agent/skills/<skill-name>`.
2. Add a `SKILL.md` with instructions.
3. Add any helper scripts.
